# KevBrad

## Building useful products with AI-assisted development

I lead product direction, research, requirements and iterative testing for Framecraft, a working local video-clipping application. I use AI assistance in implementation and debugging, then evaluate the result through real workflows and measured tests.

### Featured project: [Framecraft](https://github.com/KevBrad/framecraft-ai)

Turn authorized long-form recordings into editable short-form stories. The app combines local Whisper transcription, explainable heuristic clip selection, caption/framing controls and genuine MP4 export.
